# Отчёт по закупу и логистике (МойСклад → Excel)

Скрипт забирает данные из МойСклад по API (только чтение) и собирает один Excel-файл.

## Запуск

```bash
pip install -r requirements.txt
python run.py --demo     # проба на выдуманных данных, токен не нужен
python run.py            # боевой отчёт
```

Токен: МойСклад → Настройки → Безопасность → Токены. Положите его в файл `.env` рядом с `run.py`:

```
MOYSKLAD_TOKEN=ваш_токен
```

Файл `.env`, папки `reports/` и `input/` в git не попадают.

## Что в отчёте

| Лист | Откуда данные | Что показывает |
|---|---|---|
| Сводка | расчёт | Главные цифры для руководителя: запас, заморозка, депозиты у заводов, предстоящие доплаты, просрочки |
| Закуп | остатки + продажи 30/90 дней | По каждой позиции: продажи в день, запас в днях, статус, сколько заказать |
| Заморозка | то же | Неликвид и излишки, отсортированы по сумме замороженных денег |
| Склады | остатки и продажи по складам | Запас, оборачиваемость и товар без продаж по каждому складу и ангару |
| Перемещения | то же | Где товара дефицит, а на другом складе он лежит: что перевезти вместо закупа |
| Базар | отгрузки контрагенту-базару | Что и сколько ушло в ангары за 30/90 дней, доля базара в продажах товара |
| Заводы | платежи, приёмки, баланс взаиморасчётов | По каждому заводу: депозит, наш долг, оплачено и принято за 30/90/365 дней, дней без приёмок |
| Платежи | исходящие платежи | Реестр платежей заводам за период |
| Помесячно | платежи, приёмки, статьи расходов | По месяцам: оплачено заводам, принято, разница, расходы на логистику |
| Логистика | `input/logistics.xlsx` (ручной ввод) | Отправки: статус, дни в пути, просрочка, ставка за м3/кг, неоплаченное |

## Как считается

- **Продаж в день** = среднее между темпом за 30 дней и темпом за 90 дней.
- **Заказать** = продаж в день × (срок поставки + страховой запас + цикл заказа) − остаток − товар в пути.
- **Срочно заказать**: остаток вместе с товаром в пути закончится раньше, чем придёт новая поставка.
- **Неликвид**: остаток есть, продаж за 90 дней нет, товар лежит дольше 30 дней.
- **Излишек**: запаса больше чем на 180 дней; замороженной считается часть сверх 180 дней.
- **Заводы** — контрагенты с группами из `[suppliers] tags`. Заказы поставщикам из МойСклад не используются.
- **Товар в пути** вы вписываете прямо в отчёт: жёлтые столбцы «В пути, шт» и «План прибытия» на листе «Закуп». Статус и «Заказать» пересчитываются в Excel сразу. При следующем запуске скрипт переносит вписанное из самого свежего отчёта в `reports/` (или из файла `--prev`).
- **Базар** — контрагенты из `[bazaar] agents`. Отгрузка им считается продажей; остатки и продажи самих ангаров в МойСклад не видны.
- **Логистика по деньгам** — статьи расходов из `[logistics] expense_items`.
- **Депозит у завода** = отрицательный баланс взаиморасчётов с заводом в МойСклад (оплачено больше, чем принято). Положительный баланс — наш долг.
- **Продажи** берутся из отчёта «Прибыльность»; если на него нет прав — из отгрузок и возвратов покупателей.
- Склады из `exclude_stores` (брак) в анализ закупа не входят.

Все пороги меняются в `config.toml`.

## Ограничения

- Если товара не было в наличии, его продажи занижены, и рекомендация к заказу тоже занижена.
- Срок поставки один на все товары. Отдельных сроков по заводам пока нет.
- Депозит виден суммой по заводу, без разбивки по заказам: платежи в МойСклад не привязаны к документам.
- Рекомендация «заказать» учитывает товар в пути, только если он вписан в жёлтый столбец. Когда товар принят на склад, сотрите число, иначе он посчитается дважды.
- Логистика ведётся вручную в `input/logistics.xlsx`: в МойСклад этих данных нет.
